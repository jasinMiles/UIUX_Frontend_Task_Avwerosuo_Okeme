DroneTV

A modern, responsive redesign of DroneTV, created for the IPAGE Group UI/UX Designer & Frontend Developer Internship practical assessment.

DroneTV is reimagined as The Digital Hub for the Drone & Emerging Technology Ecosystem— a dark, technology-forward interface that feels like a connected platform rather than a basic media site.

Features

- Fully responsive layout (desktop, laptop, tablet, mobile)
- Sticky navigation with a working mobile hamburger menu
- Reusable component system: buttons, cards, tags, navbar, footer
- Course category filtering (All / Drone / GIS / AI / Photography)
- Client-side login validation (required fields + email format)
- Interactive user dashboard: sidebar sections, progress bar, saved items, logout

Technologies used

- HTML5 (semantic markup)
- CSS3 (custom properties, Grid, Flexbox — no framework)
- Vanilla JavaScript (no libraries)
- Figma (design & prototype)


How to run

Clone the repository and open `index.html` in a browser — no build step or dependencies required.
